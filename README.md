# Labour Consultancy Portal

A production-ready MERN stack portal for workers, employers, consultancies and admins.

## Features
- JWT authentication and role-based access
- Worker profiles, employer profiles and job postings
- Application workflows and admin controls
- Responsive React frontend with secure API integration

## Structure
- client/ for React + Vite frontend
- server/ for Express + MongoDB backend

## Quick Start
1. Install backend dependencies: `cd server && npm install`
2. Install frontend dependencies: `cd client && npm install`
3. Start MongoDB locally
4. Create `.env` from `.env.example`
5. Run backend: `npm run dev`
6. Run frontend: `npm run dev`
